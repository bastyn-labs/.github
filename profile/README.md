# BASTYN Labs

BASTYN Labs is where the BASTYN cybersecurity organisation builds in the open and experiments in private.

We work on security for autonomous AI agents. Our rule is to say less and be right: a finding has to rest on something we can point to in the code.

## Two tracks

| Track | Visibility | What it is |
|---|---|---|
| Community | Public, open source | Tools we maintain and accept contributions to. |
| Private lab | Private | Early research and prototypes. Not listed here. A project moves to Community only when it is ready to be maintained in public. |

## Community projects

| Project | What it does | Status |
|---|---|---|
| [bastyn-scan](https://github.com/BASTYN-labs/bastyn-scan) | A single-binary static scanner for AI agent repositories (Python, TypeScript, JavaScript, MCP configs, Dockerfiles, Compose files). Runs locally, no account, SARIF output. | Alpha, Apache-2.0 |

## Contributing

Open an issue before a large change. Each repo's `CONTRIBUTING.md` lists the checks CI runs. Everyone is expected to follow the [Code of Conduct](https://github.com/BASTYN-labs/bastyn-scan/blob/main/CODE_OF_CONDUCT.md).

## Reporting a vulnerability

Don't open a public issue. Follow the `SECURITY.md` in the affected repo.
